# Navdeep Singh — Portfolio

A responsive personal portfolio introducing Navdeep Singh, a BCA Artificial Intelligence and Machine Learning student. The site presents selected projects, background, certificates, articles, experience, and contact links.

## Features

- Responsive portfolio layout with profile, work, about, certificates, articles, experience, and contact sections
- Projects/About tabs and a light/dark theme toggle
- Accessible navigation, reduced-motion support, and responsive project screenshots
- Built with plain HTML, CSS, and JavaScript; no build step or package installation required

## Built with

This project was built with HTML, CSS, and JavaScript in Visual Studio Code, with GitHub Copilot assistance.

## Run locally

Open `index.html` in a browser, or serve the project directory with a local static server. For example, if you have the VS Code Live Server extension installed, open `index.html` and choose **Open with Live Server**.

## Project structure

```text
.
├── index.html
├── script.js
├── style.css
└── assets/
    ├── img/       # Profile, article, and responsive preview images
    └── project/   # Selected project screenshots
```

The page loads web fonts from Google Fonts and the Lordicon script from its CDN, so those externally hosted resources require an internet connection.
